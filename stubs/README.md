# stubs

Исходные заготовки упражнений. Каждый файл — это тот же файл, что и в
`src/pytutor/exercises/<модуль>/`, но с телами-`raise NotImplementedError` вместо
решений.

«Данные» (заранее реализованные в рамках упражнения) функции и классы — например
`format_currency` в `ex03`, `_check_length` и `__init__`/`warn`/`debug` в `ex04`,
`Point` в `ex12`, `_scaled` в `ex15` — оставлены реализованными.

Сброс упражнений к этим заготовкам выполняет скрипт:

```bash
uv run python scripts/reset_exercises.py
```

Не редактируйте файлы здесь вручную, если не хотите менять точку возврата: именно
из этого каталога восстанавливается исходное состояние.
